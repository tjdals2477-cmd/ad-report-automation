# 광고 리포트 자동화

주간·월간 광고 데이터 파일을 업로드하면 KPI 카드, 광고 매출 대비 광고비, 캠페인별 매출 요약, 판매상품 TOP 10을 자동으로 만드는 로컬 웹 프로그램입니다.

`streamlit_app.py`는 Streamlit Community Cloud 배포용 진입 파일입니다. GitHub 저장소에 이 폴더의 파일을 올리고 Streamlit에서 해당 파일을 선택하면 `streamlit.app` 주소로 실행할 수 있습니다.

## 온라인 앱

[광고 리포트 자동화 실행하기](https://ad-report-automation.streamlit.app/)

## 실행

1. `start.bat`을 더블클릭합니다.
2. 브라우저가 열리면 `.xlsx`, `.xlsm`, `.csv`, `.tsv` 파일을 올립니다.
3. 자동 선택된 시트와 열 이름을 확인합니다.
4. `보고서 생성`을 누릅니다.
5. `PDF로 저장 / 인쇄`에서 프린터를 `PDF로 저장`으로 선택합니다.

처음 확인할 때는 `sample_data` 폴더의 캠페인·상품 CSV 두 파일을 함께 올려 테스트할 수 있습니다. 화면 상단의 `샘플 보기`는 업로드 없이 보고서 디자인만 빠르게 보여줍니다.

프로그램은 `127.0.0.1`에서만 실행되며 업로드한 파일을 외부로 전송하지 않습니다. 파일 데이터는 메모리에만 유지되고 프로그램을 종료하면 사라집니다.

## 입력 데이터 기준

캠페인 집계에는 아래 열이 필요합니다.

- 캠페인명
- 광고비
- 매출

상품 TOP 10에는 아래 열이 필요합니다.

- 상품명
- 매출액

옵션 ID, 판매 수량, 클릭수, 주문수, 전환율은 선택 항목입니다. 전환율은 `주문수 ÷ 클릭수`를 우선 사용하고, 두 열이 없으면 업로드 파일의 전환율 열을 사용합니다.

한 엑셀 파일 안에 캠페인 시트와 상품 시트가 따로 있어도 되고, 두 파일을 동시에 업로드해도 됩니다. 열 이름이 다른 경우 화면에서 직접 연결할 수 있습니다.

## 참고

- 구형 `.xls`는 Excel에서 `.xlsx`로 다시 저장한 뒤 사용하세요.
- 합계가 중복되지 않도록 KPI는 선택한 캠페인 데이터 시트를 기준으로 계산합니다.
- 빈 값, `원`, `%`, 쉼표가 포함된 숫자도 자동으로 정리합니다.
- 기본 포트는 `8765`입니다. 충돌할 경우 환경 변수 `AD_REPORT_PORT`로 변경할 수 있습니다.
